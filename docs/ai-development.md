# Разработка Rollout с Codex

## Агент и участие человека

На этапе финальных проверок и CI использовался Codex на базе GPT-6. Точная версия модели в сессии не указана. Ранние этапы восстановлены по истории Git и журналу изменений.

Пользователь задал стек, сценарии Rollout MVP и правила работы с репозиторием. Codex добавил E2E, провёл проверки в Chromium, исправил подключение полей Taiga UI и настроил CI. Результаты человеческого ревью этого раздела в репозитории пока не зафиксированы.

## Исправления по результатам проверок

- Уже запущенный локальный API удерживал файлы сборки Debug на Windows. E2E использует Release и отдельные порты 4210 и 5165, чтобы запускаться рядом с обычным профилем разработки.
- В Chromium поля названия, ключа и поиска отображались как поля браузера. Переход на директиву `tuiInput` восстановил размеры, цвета и индикаторы фокуса Taiga UI. Повторная проверка включала отображение ошибок валидации формы.
