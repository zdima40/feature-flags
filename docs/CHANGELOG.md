# CHANGELOG

## [Unreleased]

### Done

- Создан backend Rollout на ASP.NET Core Minimal API с зафиксированными версиями SDK и NuGet-зависимостей.
- Добавлены пять маршрутов API с типизированными DTO, Problem Details и Swagger UI в Development. Список поддерживает поиск и фильтр по статусу. Список и история используют серверную пагинацию.
- Добавлена миграция SQLite с независимыми настройками трёх окружений и уникальностью ключа без учёта регистра. Создание и обновление флага сохраняют данные вместе с аудитом. Повторное обновление с теми же значениями сохраняет даты и историю.
- Добавлены xUnit-тесты бизнес-правил и интеграционные тесты с миграциями и перезапуском приложения на временной SQLite. В Swagger UI проверены все пять маршрутов, создание флага и чтение списка.
- Зафиксированы Node.js 24.18.0, Angular 22.2.6, Taiga UI 5.33.0, Tailwind CSS 4.3.5 и инструменты frontend. Проверена чистая установка из npm lock-файла со строгой проверкой peer dependencies. Согласовано временное исключение для `picomatch` 4.0.7 ([GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf)).
- Создано standalone-приложение Rollout со строгой проверкой TypeScript и шаблонов. Angular dev-сервер проксирует `/api/**` на локальный ASP.NET Core API. Проверены сборка, smoke-тест и ответы списка и вложенного маршрута через прокси с отдельной SQLite.
- Подключены графитовая тема Taiga UI с cyan-акцентом и адаптивные утилиты Tailwind. В Chromium на ширинах 390 и 1440 px проверены кнопка, поле ввода, таблица и диалог. Preflight отключён, чтобы сохранить стандартные отступы текста в диалоге. Настроены Angular ESLint для TypeScript и шаблонов, Prettier и Vitest с Angular TestBed.
- Добавлена страница `/flags` с типизированным HTTP-сервисом и таблицей флагов. Таблица показывает настройки окружения и время последнего изменения.
- Список поддерживает выбор окружения, поиск по имени и ключу, фильтрацию по статусу и серверную пагинацию с общим количеством. При смене фильтров список возвращается на первую страницу.
- Добавлено быстрое переключение статуса с подтверждением API и сохранением прежнего состояния при ошибке. Список показывает загрузку, пустую выдачу и сообщения об ошибке или успехе. Доступны переходы к маршрутам создания, редактирования и истории.
- Тесты Vitest и Angular TestBed проверяют параметры GET и тело PATCH через `HttpTestingController`, состояния списка, сброс пагинации и оба результата переключения статуса.
- Добавлена общая типизированная Reactive Form для создания и редактирования флага. В режиме редактирования форма загружает общие поля и настройки всех окружений и блокирует поле ключа.
- Подключены создание, сохранение и отмена. Форма проверяет поля до отправки и показывает результат API. Настройки сохраняются для выбранного окружения, а черновики других окружений остаются в форме при переключении. Сохранение и повторное переключение проверены в Chromium на ширине 390 px с отдельной SQLite.
