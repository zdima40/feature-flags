# CHANGELOG

## [Unreleased]

### Done

- Создан backend Rollout на ASP.NET Core Minimal API с зафиксированными версиями SDK и NuGet-зависимостей.
- Добавлены пять маршрутов API с типизированными DTO, Problem Details и Swagger UI в Development. Список поддерживает поиск и фильтр по статусу. Список и история используют серверную пагинацию.
- Добавлена миграция SQLite с независимыми настройками трёх окружений и уникальностью ключа без учёта регистра. Создание и обновление флага сохраняют данные вместе с аудитом. Повторное обновление с теми же значениями сохраняет даты и историю.
- Добавлены xUnit-тесты бизнес-правил и интеграционные тесты с миграциями и перезапуском приложения на временной SQLite. В Swagger UI проверены все пять маршрутов, создание флага и чтение списка.
